# AI Doc Assistant

AI-powered engineering workspace that analyzes codebases, generates documentation, explains project architecture, detects issues, and helps developers onboard faster.

## Features

- Upload single files
- Upload full project folders
- Drag and drop source files
- Detect programming languages
- Generate project summaries
- Detect Flask routes
- Export documentation as PDF, Markdown, or README
- OpenAI API ready
- Rule-based fallback engine
- Dark mode
- Responsive UI
- AI bug analyzer for traceback and error logs
- Explains errors in simple developer-friendly language
- Suggests likely causes and fixes
- Helps junior developers debug faster

## Tech Stack

- React
- Flask
- Python
- JavaScript
- OpenAI API
- jsPDF
