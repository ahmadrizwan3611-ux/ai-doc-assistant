# AI Doc Assistant

AI Doc Assistant is a React and Flask based documentation generator that analyzes source code files and project folders, then generates clean technical documentation.

## Features

- Upload single files
- Upload full project folders
- Drag and drop source files
- Detect programming languages
- Generate project summaries
- Detect Flask routes
- Export documentation as PDF, Markdown, or README
- OpenAI API ready
- Rule-based fallback engine
- Dark mode
- Responsive UI

## Tech Stack

- React
- Flask
- Python
- JavaScript
- OpenAI API
- jsPDF
